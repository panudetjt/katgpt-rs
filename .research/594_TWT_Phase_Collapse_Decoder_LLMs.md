## TL;DR

ViTs settle into depthwise-contiguous computational phases: the L×L matrix of expected cosine distances between intermediate token representations is block-diagonal. TWT exploits this **post-hoc**: (1) partition depth into contiguous ε-redundant blocks by min-max dynamic programming, (2) **audition** surrogate candidates (each teacher layer in the block + a weight-averaged operator) by local mapping error on a calibration batch, (3) distill a single-surrogate-per-block student with deep supervision. Result: 12→5 layers at ~43% params / ~50% FLOPs, competitive on natural images, **improved** downstream on histopathology (collapse denoises augmentation-sensitive intermediate variation — 38–50% std reduction at block boundaries).

**Distilled for the stack:** the pipeline's first two stages are fully modelless (forwards + DP + argmin — zero gradients), and they compose into a **zero-recovery-training deployment posture** the paper never ships: auditioned weight-average surrogate + closed-form α/β corrections + deterministic re-ternarization, GOAT-gated on decode throughput against pre-registered quality budgets. That posture on **ternary/quantized GGUF checkpoints** is the unpinned combination this note files.

**Re-pinned novelty claim (post-§4):** *First transfer of the TWT-style phase-collapse pipeline (min-max DP partition over the L×L layer-similarity matrix + auditioned-surrogate selection by local mapping error) to decoder LLMs on ternary/quantized GGUF checkpoints in a zero-recovery-training posture (weight-average surrogate + closed-form α/β corrections + deterministic re-ternarization arms), GOAT-gated on decode throughput against pre-registered quality budgets.*

## 1. Paper core findings (the load-bearing five)

1. **Block-diagonal phase structure is real and universal** (Fig. 2): DeiT-III, DINOv2, DINOv3 all show contiguous high intra-block similarity of layer outputs over a calibration set — supervised and self-supervised alike. ε-functional redundancy (Eq. 3): all layers in a block behave similarly on visited states.
2. **Surrogate choice is the whole design space** (§2.1): Raptor/BRH = parameter-tied layer unrolled k times (params ↓, compute unchanged); TOAST/NOSE = non-mixing surrogates (closed-form linear / MLP — compute ↓, expressivity ↓); **TWT = ONE full ViT layer per block** (token-mixing expressivity retained, both params and compute ↓).
3. **Min-max DP partition** (§3.1): `min_P (m, max_j S[s_j,e_j]) s.t. S[s_j,e_j] ≤ ε` — minimize block count, tie-break on worst-case intra-block discrepancy. Deterministic merge plan; ε is a geometric dial (Appendix D: monotone in retained-block count).
4. **Auditioning** (§3.2): candidate pool per block = {each member layer} ∪ {weight-averaged operator f̄_j, norm params isolated}; argmin of local mapping error ‖f(h_{s−1}) − h_e‖² on a small calibration batch. Init-only in the paper — but a valid **final** surrogate in its own right (untested there).
5. **Collapse denoises OOD** (§4): intrinsic-dimension + augmentation-variance analysis — the student tracks the teacher's coarse ID trajectory with 37.8–49.6% lower augmentation sensitivity; downstream histopathology **improves** over the uncompressed baseline (+0.9 to +5.9 on several heads). In-distribution natural images: preserve at best. Dense/segmentation: most sensitive.

## 3. Novelty gate (§1.5, scored honestly)

- **Q1 No prior art?** **NO** at component level — TWT itself publishes the DP partition + auditioning (ViT); LaCo (EMNLP 2024, arXiv:2402.11187) publishes zero-recovery-training LLM layer collapse via RDSC — `θ_l + Σ(θ_{l+k} − θ_l)`, a sum of parameter DIFFERENCES (residual-scaling), not a plain weight average — greedy grouping, no auditioning pool, no DP; LoRP (training-free one-shot LLM depth pruning) and ReplaceMe (NeurIPS 2025, arXiv:2505.02819, training-free linear replacement) publish the training-free LLM class; ShortGPT (arXiv:2403.03853, Block Influence removal) + Gromov (arXiv:2403.17887) publish removal-based redundancy exploitation. Internally, note 269 already records the mid-layer-collapse phenomenon (normalized matrix entropy → ~0 by ~layer 10, de Llano et al. 2026) and hydra + sink-aware exploit it — the PHENOMENON carries no novelty here and never carried the claim. The **combination** (decoder-LLM × quantized-GGUF × auditioned zero-training surrogate × DP partition × throughput gate) is unpinned territory, and the quantized-checkpoint axis returned no prior art across two independent search rounds. Partial.
- **Q2 New behavior class?** No — model compression via depth reduction is an existing class. Better compression dial, not a new capability.
- **Q3 Product selling point?** Weak/derivative: "swarm NPC brains run at half depth at bounded drift" is a cost selling point competitors could match with LaCo. Not a headline capability.
- **Q4 Force multiplier?** YES — the S-profiler + min-max partition serve ≥2 surfaces beyond collapse (ternary scale-group boundaries, KV-cache segment tiers, tick-series regime segmentation, ΔS as a quant-damage validator).

**3/4 → NOT Super-GOAT. GAIN** (fusion idea, combination-novelty gated by the PoC — no "candidate" wording, the issues ARE the commitment).

## 4. Game-context reframe (priority #1 — done) and consumer reframe (priority #2 — done)

**Game:** collapsed brains = fewer ternary matvecs per NPC per tick (`npc_brain` over katgpt-core plasma_path) — a GOAT-passing collapse directly raises the 1000-NPC swarm ceiling at the fixed 20 Hz budget; the S-profiler also applies to any stacked-layer runtime (riir-engine `hla/` phase structure is unmeasured). But game brains are shallow — the value concentrates on the 27B serving models first; game consumption is a downstream follow-up gated on 022 (re-open trigger recorded, no riir-ai filing now — nothing to consume yet).

**Healer:** no consumer — the healer's drafter (`TernaryDraftModel`, 8-template) has no depth to collapse, and the corpus/retrieval stack is not a depth-stacked sequential transform. Recorded as checked-empty.

**Perf league (#3):** decode is GPU-busy-bound at the stage-sum intrinsic (riir-ai AGENTS) — removing layers moves the league number directly. This is why the GOAT gate is decode throughput.

## Caveats

- **ViT→decoder non-transferables** (model-based advocate §3, all gated not asserted): 63× late-layer norm explosion is ViT-specific (pre-norm RMSNorm LLMs don't exhibit it — LayerScale stays as near-free insurance only); causal hidden states are position-dependent → the DP must consume position-stratified discrepancies (prompt/head/generation bands, conservative min across bands) else the partition is BOS-band noise; generation is the sensitive lane (TWT's own dense-vs-classification result predicts our risk ordering — classification-shaped lanes first); GDN gate/decay params must never be averaged (exp/sigmoid distortion — audition catches it); the histopathology IMPROVEMENT is class-conditional (OOD augmentation-noise) — do not assume it transfers.
- **Prior-art thinness:** web verdicts (A)–(E) rest on ~20 queries with timeouts on the survey + quant-interaction searches; LoRP/TOAST arXiv IDs unverified. The quant axis (C) is the claim's load-bearing open axis and the thinnest — 022's landing should re-run verdict C before any public novelty wording.
- **Reasoning-harm caution:** "On the Limits of Layer Pruning for Generative Reasoning" (arXiv, Aug 2026) — layer reduction harms reasoning/test-time scaling. Generation/reasoning lanes carry this risk axis explicitly in 022's gate; collapse claims are scoped to throughput-lane deployments.
- **Affordability wall (training track):** PQ2-27B LoRA backward is UNPROVEN in this stack (riir-train Plan 352: 4090 OOM'd Gemma-2-2B in the full-bandwidth rig) — 423 Phase 0 is a 30-min memory probe before any 27B commitment; the 2B Metal fallback settles the recipe at ~10–30 M3-h.
- **Layer-type mixing is a DECODER-specific transfer gap the paper never faces (verdict round-2 blocker, verified):** a ViT is layer-homogeneous by construction; laya is NOT — `global_attn_every_n_layers=3` (full attention on layers 0, 3, …), `local_attention=128` sliding window on the rest, and DIFFERENT RoPE thetas per type (`rope_theta_full` vs `rope_theta_slide`, riir-infer-laya config.rs:141-150); gemma-2 alternates 4096-window sliding with global layers under ONE theta (its GGUF carries no per-type rope keys — verified via riir-train's `scripts/plan402_gguf_probe.py`). The 022 feasibility split follows: RoPE-theta mismatch and GDN-vs-attention are HARD-INFEASIBLE pairs; mask-type (sliding vs global) merges are allowed when theta matches, with the audition picking the mask type and the above-window calibration length making that choice testable. **Collapse-ceiling consequence:** laya's G-S-S pattern under distinct thetas caps m at ≈ 2L/3 — a ~33% depth-reduction ceiling, BELOW TWT's ~50% — so a ≤33% laya result is the CONSTRAINT working, not the method underperforming. Recorded as a first-class adaptation constraint, not an implementation detail.
